# Sorcerer's Code

A small Python command-line app to build on as you decide what to make.

## Requirements

Python 3.10 or newer. No third-party dependencies, credentials, or services are needed.

## Run

From the repository directory:

```sh
python3 sorcerers_code.py
python3 sorcerers_code.py --name Merlin
```

## Test

```sh
python3 -m unittest -v
```

Start with `sorcerers_code.py` to change the app's behavior. Tests live in
`test_sorcerers_code.py` and use Python's built-in test framework.
